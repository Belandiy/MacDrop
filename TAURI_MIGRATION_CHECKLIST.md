# Чек-лист тестирования MacDrop (Миграция на Tauri v2)

Интерактивный список проверок для верификации каждого User Journey и edge-кейсов после перехода с Electron на Tauri v2. Отмечайте пройденные пункты: `- [x]`.

## 1. Запуск, окно и нативные элементы macOS

- [X] **1.1. Перемещение окна (Window Drag)**

  - *Действие:* Зажать ЛКМ на пустом месте верхней панели (шапка 38px) и потянуть.
  - *Ожидание:* Окно плавно перемещается за курсором без выделения текста.
  - *Edge-кейс:* Убедиться в наличии атрибута `data-tauri-drag-region`, так как `-webkit-app-region` в Safari WebKit может игнорироваться.
- [X] **1.2. Двойной клик по шапке**

  - *Действие:* Сделать двойной клик по пустому месту панели заголовка.
  - *Ожидание:* Окно переходит в режим Zoom / Maximize и возвращается обратно.
- [X] **1.3. Кнопка Minimize (Желтая)**

  - *Действие:* Кликнуть на желтую кнопку в Traffic Lights.
  - *Ожидание:* Окно сворачивается в macOS Dock.
- [X] **1.4. Кнопка Zoom / Maximize (Зеленая)**

  - *Действие:* Кликнуть на зеленую кнопку в Traffic Lights.
  - *Ожидание:* Окно разворачивается на весь экран с нативной macOS-анимацией переключения пространства (Fullscreen); повторный клик восстанавливает исходный размер.
- [X] **1.5. Кнопка Close (Красная) и жизненный цикл**

  - *Действие:* Кликнуть на красную кнопку.
  - *Ожидание:* Окно скрывается (`hide`), но приложение продолжает работать в фоне и доступно в строке меню (Tray).
  - *Edge-кейс:* Процесс не должен аварийно завершаться (`app exit`).
- [X] **1.6. Иконка в Menu Bar (macOS Tray) — ЛКМ**

  - *Действие:* Кликнуть ЛКМ по иконке MacDrop в правом верхнем углу меню macOS.
  - *Ожидание:* Окно мгновенно появляется/скрывается (toggle) с возвратом фокуса.
- [X] **1.7. Иконка в Menu Bar (macOS Tray) — ПКМ**

  - *Действие:* Кликнуть ПКМ по иконке в трее.
  - *Ожидание:* Открывается нативное меню:
    - `🖥️ Показать MacDrop` (разворачивает окно)
    - `📂 Открыть папку MacDrop` (открывает целевой каталог в Finder)
    - `❌ Выход` (корректно завершает приложение и фоновые демоны)
- [X] **1.8. Ресайз окна и минимальные размеры**

  - *Действие:* Потянуть за края окна для уменьшения и увеличения.
  - *Ожидание:* Окно не уменьшается ниже 640x400; верстка не ломается.
- [X] **1.9. Ресайз боковой панели (Sidebar)**

  - *Действие:* Перетащить вертикальный разделитель сайдбара влево/вправо.
  - *Ожидание:* Ширина меняется в пределах 170–340px и сохраняется в `localStorage` после перезапуска.
- [X] **1.10. Эффект размытия фона (Window Vibrancy)**

  - *Действие:* Переместить окно поверх светлых и темных окон других программ.
  - *Ожидание:* Нативное размытие macOS (`UnderWindowBackground`) отображается без артефактов и черных рамок, сквозь полупрозрачный фон интерфейса.

## 2. Перетаскивание файлов (Drag & Drop)

- [X] **2.1. Drop одного файла из Finder в центральную зону**

  - *Действие:* Перетащить обычный файл (например, `.png` или `.pdf`) в дропзону.
  - *Ожидание:* Появляется визуальный ховер, имя файла отображается, после отпускания стартует передача.
  - *Реализовано:* Нативный `onDragDropEvent` через Webview API с физическим хит-тестингом и получением абсолютных путей файлов.

- [X] **2.2. Drop группы файлов (Batch Drag)**

  - *Действие:* Перетащить одновременно 5+ файлов разного размера.
  - *Ожидание:* Все файлы ставятся в очередь, счетчик файлов отображает точное количество (`+N`).

- [X] **2.3. Drop на конкретное устройство в сайдбаре**

  - *Действие:* Перетащить файл прямо на элемент нужного устройства в списке слева.
  - *Ожидание:* Подсвечивается конкретная плитка устройства, отправка идет именно на выбранный узел.
  - *Реализовано:* Hit-testing курсора по `[data-device-id]` с интерактивной синей подсветкой узла в сайдбаре.

- [X] **2.4. Drop папки с вложенными файлами**

  - *Действие:* Перетащить каталог с подпапками.
  - *Ожидание:* Каталог корректно упаковывается в ZIP и передается получателю.

- [X] **2.5. Файлы со спецсимволами и кириллицей**

  - *Действие:* Сбросить файл с именем вроде `Документ [версия 2.0] & правки.docx`.
  - *Ожидание:* Кодировка URI / UTF-8 не ломает путь к файлу на бэкенде Rust (`urlencoding::decode` с поддержкой пробелов).

- [ ] **2.6. Большие файлы (> 2 ГБ)**

  - *Действие:* Сбросить видеофайл размером более 2–4 ГБ.
  - *Ожидание:* Нет зависания UI-потока, 64-битный размер вычисляется корректно. (Включено в Фазу 4: потоковый трансфер).

- [X] **2.7. Ложный дроп (Текст, URL, картинка из браузера)**

  - *Действие:* Перетащить выделенный текст или веб-картинку из браузера в окно.
  - *Ожидание:* Приложение игнорирует нефайловый drop без ошибок в консоли.

## 3. Нативные диалоги выбора файлов (RFD Dialogs)

- [ ] **3.1. Кнопка «Выбрать файлы»**
  - *Действие:* Нажать на кнопку выбора файлов в дропзоне.
  - *Ожидание:* Открывается нативный файловый диалог macOS; выбор подтверждает отправку. (Ошибка порта `8384` вынесена в Фазу 4.1).

- [X] **3.2. Множественный выбор файлов в диалоге**

  - *Действие:* В диалоге через Cmd/Shift выбрать несколько файлов.
  - *Ожидание:* Все выбранные пути передаются в `commands::send_dropped_files`.
  - *Реализовано:* Активация фокуса приложения `activateIgnoringOtherApps: true` на macOS и корректный сбор всех выбранных дескрипторов.

- [X] **3.3. Кнопка «Выбрать папку»**

  - *Действие:* Нажать «Выбрать папку».
  - *Ожидание:* Открывается диалог выбора каталога; путь передается на бэкенд, папка архивируется и отправляется.
- [X] **3.4. Отмена в диалоге**

  - *Действие:* Открыть диалог и нажать «Отмена» или Esc.
  - *Ожидание:* Диалог закрывается, UI возвращается в исходное состояние без логов `Unhandled Rejection`.

## 6. Передача файлов (File Transfer Engine)

- [ ] **6.1. Исходящая передача файла**
  - *Действие:* Отправить файл на сопряженный узел.
  - *Ожидание:* В списке *Transfers* появляется активная строка со статусом передачи.
- [ ] **6.2. Прогресс-бар и скорость передачи**
  - *Действие:* Отправить файл размером 200+ МБ.
  - *Ожидание:* Прогресс плавно растет, отображаются проценты, скорость (МБ/с) и оставшееся время (ETA).
- [ ] **6.3. Отмена активной передачи**
  - *Действие:* Нажать кнопку отмены (крестик) во время активного трансфера.
  - *Ожидание:* Передача немедленно обрывается, статус сбрасывается, частичный временный файл удаляется.
- [ ] **6.4. Входящий прием файла**
  - *Действие:* Принять файл с другого устройства при включенном автоприеме.
  - *Ожидание:* Файл сохраняется в целевую папку без блокировки UI.
- [ ] **6.5. Коллизия одинаковых имен файлов**
  - *Действие:* Принять файл с именем, которое уже есть в целевой папке.
  - *Ожидание:* Файл не перезаписывается молча; создается копия вида `file (1).ext`.
- [ ] **6.6. Быстрое открытие файла и папки**
  - *Действие:* В списке завершенных передач кликнуть по полученному файлу и по кнопке папки.
  - *Ожидание:* Файл открывается в системном приложении (`open_file`), а папка — в Finder (`open_folder`).
- [ ] **6.7. Фильтры истории передач (All / Active / Completed)**
  - *Действие:* Переключить вкладки фильтра в правом нижнем углу.
  - *Ожидание:* Таблица корректно фильтрует строки по их состоянию.
