# 🚀 MacDrop

Кроссплатформенное приложение для быстрого и безопасного обмена файлами и папками между **Mac** и **Windows ПК** через локальную сеть и интернет.

---

## 📥 Установка и запуск

### 💻 Windows
1. Скачайте **`MacDrop 1.0.0.exe`** (Portable) со страницы [Releases](https://github.com/Belandiy/MacDrop/releases).
2. Запустите файл.
   > **Примечание:** если появится экран *Windows SmartScreen*, нажмите **«Подробнее»** → **«Выполнить в любом случае»**.

---

### 🍏 macOS
1. Скачайте нужный файл со страницы [Releases](https://github.com/Belandiy/MacDrop/releases):
   - **`MacDrop-1.0.0-arm64.dmg`** — для Mac на процессорах Apple Silicon (M1 / M2 / M3 / M4);
   - **`MacDrop-1.0.0.dmg`** — для Mac на процессорах Intel.
2. Откройте `.dmg` и перетащите иконку **MacDrop** в папку **«Программы»** (`Applications`).
3. Откройте **Терминал** и выполните команду для снятия системного карантина Gatekeeper:
   ```bash
   xattr -cr /Applications/MacDrop.app
   ```
4. Запустите **MacDrop** из папки «Программы» или через Spotlight (`Cmd + Пробел`). Иконка появится в верхней строке меню (Menu Bar).

---

## 🔗 Сопряжение устройств (1 раз)

1. **На ПК:** в окне MacDrop нажмите **«Связать»** — отобразится ваш код (например: `PC-5040`).
2. **На Mac:** в окне MacDrop перейдите во вкладку **«Ввести код Windows ПК»**, введите код и нажмите **«Подключить»**.
3. **Готово!** Устройства связаны навсегда:
   - Файлы можно перетаскивать мышкой прямо в окно программы на любом из компьютеров.
   - Либо просто сохранять файлы в выбранную папку (`E:\MacDrop` на ПК / `~/Desktop/MacDrop` на Mac).

## 🛠️ Сборка из исходников

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка под Windows (.exe)
npm run build:win

# Сборка под macOS (.dmg и .zip)
npm run build:mac
```
Готовые сборки сохраняются в каталог `release/`.
