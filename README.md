# 🚀 MacDrop

**MacDrop** — элегантное, красивое и быстрое кроссплатформенное приложение для двустороннего обмена файлами между **Mac** и **Windows ПК** (по умолчанию диск `E:\MacDrop`), работающее в фоновом режиме:
- ⚡ **В локальной сети:** передача на максимальной скорости Wi-Fi / гигабитного кабеля.
- 🌐 **Через Интернет:** связь работает, даже если компьютеры в разных сетях (кафе, мобильный хотспот, работа) без «белого» IP.
- 📁 **Выбор папки на обоих устройствах:** на ПК вы можете выбрать любую папку на диске `E:\`, `D:\` или `C:\`, а на Mac — `~/Desktop/MacDrop` или любую другую.
- 🎯 **Drag-and-Drop:** перетаскивайте файлы прямо в окно приложения или просто сохраняйте их в выбранную папку.
- 🔔 **Нативные уведомления:** системные баннеры Windows 10/11 и macOS при получении новых файлов.

## 🖥️ Скриншоты и возможности

| Возможность | Windows ПК | macOS |
| :--- | :--- | :--- |
| **Расположение** | Системный трей (у часов) | Верхняя строка меню (Menu Bar) |
| **Папка по умолчанию** | `E:\MacDrop` | `~/Desktop/MacDrop` |
| **Смена папки** | Кнопка «Выбрать другую...» (Проводник) | Кнопка «Выбрать другую...» (Finder) |
| **Отправка файлов** | Drag-and-Drop в окно или копирование в папку | Drag-and-Drop в окно или копирование в папку |
| **Автозагрузка** | Запуск в трее при старте Windows | Запуск в строке меню при входе в macOS |

## 📦 Быстрый старт

### 1. На Windows ПК:
1. Запустите `MacDrop.exe`.
2. Приложение появится в системном трее и откроет окно.
3. Проверьте папку сохранения (по умолчанию `E:\MacDrop`). При необходимости нажмите **«Выбрать другую...»**.
4. Нажмите **«Связать»** — на экране появится ваш **Код** (например: `PC-4821`) и QR-код.

### 2. На Mac:
1. Запустите `MacDrop.app` (перетащите в папку «Программы»).
2. Нажмите **«Связать»** -> **«Ввести код Windows ПК»**.
3. Введите код с экрана ПК (например: `PC-4821`).
4. Готово! Устройства связаны навсегда.

## 🛠️ Сборка из исходников

### Требования:
- Node.js 18+ (рекомендуется v22)

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки (Hot Reload)
npm run dev

# 3. Сборка для Windows (.exe установщик и Portable .exe)
npm run build:win

# 4. Сборка для macOS (.dmg и .app)
npm run build:mac
```
Готовые сборки сохраняются в папку `release/`.
